## モデル・教師・統一条件

## 採用判断・次の作業

Qを標準AIや収集に導入しない。MCTS128/深さ4は強さの基準のまま。小規模な学習AIプレイ確認を行う基盤には進めるが、未使用seedでMCTSを上回るという主張はできない。

次に優先するのは、大型モデルではなく、**学習対象と続行方針をそろえた、同一rootの候補差教師**。再現性に合格する複数seedの中盤/スイカ後rootで共通未来を複数用意し、方策依存のreturnと相対差を保存する。例えば固定したMCTS続行なら教師方針が学習元に近づくが、計算費用は今回のheuristicより増えるため別予算が必要。密集後半prefixの失敗を無視して教師を作らない。成功/失敗両方を保持し、19の新規Testは方式固定後の一度の評価まで保護する。
