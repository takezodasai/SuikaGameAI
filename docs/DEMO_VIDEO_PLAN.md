# 紹介動画の構成案

実プレイ動画はまだ掲載していない。READMEの画像は実ログの描画。
動画は実際のプレイから作り、AIの成功や表示を合成した映像にはしない。

| 時間 | 映像 | 伝えること |
|---|---|---|
| 0〜5秒 | スイカ生成・連鎖 | 動くものを最初に見せる |
| 5〜15秒 | ゲーム画面とタイトル | Unityの物理予測を使うMCTS |
| 15〜40秒 | 一つの判断を丁寧に | 候補・探索回数・落下結果 |
| 40〜60秒 | 実プレイを早送り | 得点と盤面の変化 |
| 最後 | 構成図・成果・未達事項 | 自己対戦→保存→学習、ダブルスイカ未達 |

- 同じゲームのログの数値だけを重ね、推定価値と実得点を区別する。
- 待機を短縮編集した場合は実際の判断時間と編集したことを表示する。
- 近似盤面開始は明記し、初期スイカを新規生成として見せない。
- 高得点の見せ場と平均性能を分ける。
- 未達成のダブルスイカを達成済みと表現しない。

候補別訪問数バーなどは今後の表示案。現時点で実装済みと宣伝しない。
まず現在のGUIで録画し、スイカ生成と一つの判断を切り出す方法が最小構成。
