# 凍結Vモデルとheuristic：12seed・自然GO対応比較

2026-10-31。出力：`Python/outputs/frozen_v_pair_12_01`。今回の12seedは開発評価用であり、今後の未使用Testとはしない。

## 結論

Vの有用な得点改善は確認できなかった。heuristic平均864.42点、V平均869.33点、対応差は+4.92点、Vの4勝8敗だった。判断計算時間はVが約3.95倍。Vを標準採用せず、MCTSを強さの基準として維持する。差の不確実性は大きく、「同等であることを証明した」という結果でもない。

## 実験条件・保護・公平性

- 実行前に12seed、交互の実行順序、指標、checkpointハッシュを`plan.json`と`analysis_rules.json`に固定。結果に応じたseed追加・除外はしていない。
- 各ゲーム540秒、実験全体10,800秒、最大1,000落下。1Playerずつ順番に実行した。全24ゲーム自然GO、打ち切り・エラー・除外0。実験処理全体3,855.33秒（約64分15秒）。追加のゲームは実行していない。
- 新しい独立Player `Unity/Builds/FrozenVPair_01`を両方式に共通使用。固定5点 `[0,.25,.5,.75,1]`、同じ合法座標変換、同じ5回の既存物理予測、同じ実ゲームGO・得点・物理設定。
- Hは既存`StepPlanner.Choose`、Vは前回と同じ凍結3モデルensembleと入力処理。モデル、重み、スコア式は変更していない。将来NEXTは既存処理と同じ確率で周辺化し、実ゲームの非公開乱数を入力しない。
- 初期公開状態は全12ペア一致。観測できた果物系列は各ペアの短い側まで一致（92〜147個）。異なる行動後の物理状態・操作tickの一致を意味せず、未観測の系列全体の一致も主張しない。
- 予約Test19とのseed・初期8果物系列の重複0。既存学習記録とのゲームseed重複も0。全12ペアは独立seed群として集計。
- 予測GO候補を除外する条件は共通。ただし全候補GO時の既存フォールバックは完全には同じでない。Hは従来のGO時刻・超過量等による選択、Vは従来のdrop成功・即時得点等による選択を維持した。この残差があるため、全差をニューラル予測だけの因果効果とはしない。
- 実ゲーム時計は判断中に停止。記録された移動・cooldown・25tickの更新以外に、推論や通信待ちだけで物理tickが進まないことを監査した。

## Vが伸びた例・失敗した例

- seed887034793では+565点、落下103→147。seed896540820では+452点、115→145。長く継続できたことは観測事実だが、どの1手が改善を起こしたかは未観測行動の自然GO returnがなく確定できない。
- seed889129964では−391点、151→127落下。seed883575464では−296点、149→122落下。同一盤面からの反実仮想比較を行っていないため、特定の一手を敗因と断定しない。
- V自身の軌跡ではHと提案が異なった判断が1,045回あり、そのうち249回はVが即時得点の低い方を選んだ。将来予測を重視していることは確認できるが、その犠牲が有効だったかはこの観測だけでは分からない。

### 予測追加得点と実測return

ここで比較する予測は「候補の予測即時得点＋予測Sceneのafterstateに対するV」。実測はその判断時から自然GOまでに実際に得た追加得点。物理誤差と続行方針の違いを含み、実状態に入力したV単体の回帰誤差とは異なる。

|V自身の軌跡・ゲーム平均|予測|実際の残り追加得点|
|---|---:|---:|
|全判断|1532.54|465.75|

終盤の過大評価は残る。最後の5判断の予測非GO集計は12ゲーム・52判断で、GO予測による将来価値0への強制を除いて確認した。Hの実際の選択にVをオフライン適用しても、最後の非GO判断群は584.21対14.25と楽観的だった。Vがプレイした軌跡だけに固有の問題ではない。

密集度別の絶対誤差が単調に増えたわけではない。Vは果物0〜9個で予測2161.80対実測845.80、30個以上では904.62対136.42となり、実現returnの低下に十分対応できていない。MCTS中心の学習時とV/Hの続行方針の違い、入力分布、予測Sceneの誤差をこの実験だけで切り分けられない。絶対値の過大評価と候補順位誤りも同一ではない。

### GO・危険候補

両方式とも、予測上の安全な代替候補があるのに予測GO候補を選んだ判断は0。これは共有フィルタの効果を含み、学習した危険認識が優秀という証拠ではない。

- 予測GO候補を選択した判断は各8回。
- Vではseed887034793の146判断目、882361349の108判断目に予測GOを選択した後、次の判断まで進めた。Hにはこの運用上の過剰予測例はない。
- 最終選択が予測非GOだったのに、次の判断前に実GOとなったゲームはV6/12、H4/12。これは予測時相と実GOの不一致であり、モデル固有の見逃し率や別候補なら生存できた確率と断定しない。
- 実GO観測時の果物種類・座標・速度等は各`trace.jsonl`と`analysis_final.json`に保存。GO後に追加物理を進めず観測した盤面であり、内部の最初のGO判定瞬間を完全保存した状態とは区別する。
