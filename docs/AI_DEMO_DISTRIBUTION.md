# AIデモの配布について

AI専用の起動・手動入力無効化・非公式表記は、配布の権利確認の代わりにはならない。
このリポジトリは既存Unityゲーム基盤を利用している。Windows向け実験用デモを配布しているが、次の権利確認は完了していない。公開したことを権利確認済みの証拠として扱わない。

| 対象 | 現在の状態 | 必要な対応 |
|---|---|---|
| 元ゲームコード | 出所・再配布条件の確認未完了 | 元プロジェクトの許諾・ライセンスを確認 |
| 果物画像・背景・UI | 出所・再配布条件の確認未完了 | 許諾を確認、または独自素材へ差し替える |
| 音声 | 出所・再配布条件の確認未完了 | 無音でも同梱される場合があるため、依存素材も確認 |
| フォント・外部パッケージ | 依存ライセンスの整理未完了 | 配布条件・必要なライセンス表記を同梱 |
| 名称・ロゴ・見せ方 | 非公式表示を追加 | 公式との誤認を避ける。これだけで法的適合を保証しない |

ソース公開にも同じ確認が必要。現在の公開状態を「権利確認済み」とは扱わない。
AI専用化は、見る人に研究デモと伝え、手動入力が実験に混ざるのを防ぐための機能。
学習モデルは推論用の213係数のみを同梱し、学習データやローカルパスは含めない。

配布方法：ビルド一式をZIP化し、SHA256・モデル世代・Windows対応・既知の制約を明記してGitHub Releasesに添付する。
exe単体では配布しない。`*_Data`・DLL・モデルなどの隣接ファイルが必要。
配布先はGitHub Releases。コード署名なしのWindows x64ビルド。Unity Editor・Pythonは不要。
利用者による第三者素材の再利用・再配布を許可するものではない。
デモは標準MCTSより強いことを保証せず、自然GOまでの長時間動作を今回の配布前テストで確認したものではない。
