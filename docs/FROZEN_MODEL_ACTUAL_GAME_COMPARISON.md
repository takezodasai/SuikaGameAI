# 学習済みQ・Vの自然GO実ゲーム比較

2026-10-31。新規学習なし。強さの標準は従来MCTSのままとする。

## 1. 今回の結論

- 同じseedで4方式が自然GOまでそろった1組では、MCTS128が1912点で最高。Vは1026点、heuristicは715点、Qは463点だった。
- Q/V/heuristicは別のもう1seedも自然GO。Vは両seedでheuristicを上回ったが、独立seedは2つだけであり標準採用しない。
- Qは両ゲームとも端の2座標しか選ばず、最後には物理予測でGOとなる右端を選択した。Q単独の標準導入を勧めない。
- 分岐では同じ新規Playerによる24手のprefixとモデル入力状態の一致を一度確認できた。ただし各分岐での一致は不安定で、続行3件は時間打ち切り、1件はprefix不一致。自然GOの新規候補教師は0件。順位や続行方針差は判定できない。
- 512回・深さ6の序盤でも4並列の判断処理量は約26%多く、全判断512回を完了。ただし自然GOゲーム/時間・終盤の品質は未測定。既存収集設定は変更しない。

## 4. 対応seedと公開情報

4方式が自然GOでそろうseed882610501の差（相手−MCTS）は、Q −1449点、V −886点、heuristic −1197点。MCTS選択を正解ラベルにはしていない。

2つの対応seedでV−heuristicは +311/+483点（平均+397点）。Q−heuristicは −252/+151点（平均−50.5点）。2seedだけで母集団の優劣を断定しない。小標本bootstrapの見かけの狭い区間を採用根拠にしていない。

seed882610501では4方式の初期公開状態が完全一致し、短いゲームに合わせた公開果物列81要素も一致した。これは果物系列の交絡を抑える確認であり、その後の物理盤面・操作tick・接触履歴の一致を意味しない。異なる行動で盤面が変わること自体は正常。seed/初期8果物系列は予約Test19と重複しなかった。今回の方式選択・実ゲーム実行に予約Test19は使っていない。

Vは移動・cooldownと25post-drop tickを含む物理予測後の状態を評価し、公開NEXTが次の保持果物になる状態定義を使用する。その時点で未公開の次NEXTは実際のspawn slotの確率で周辺化し、実ゲームの確定未来を入力しない。物理予測GOは未来価値0。Qの保持y・cooldownの既知/欠損処理は学習時のpre-state定義に合わせた。

全候補GOの場合のfallbackは完全には同じでない。Cは合法な落下候補を優先して即時得点＋未来0で選び、Dは既存のGO tick・超過量などによる順序を使う。この違いを含むAI同士の比較であり、差の全てをVの学習だけに帰属しない。

同じ観測時相を狙っていても、coldな予測Sceneと実ゲームの接触状態が完全一致するわけではない。今回それを修正したり、正確な実ゲームafterstateだと扱ったりしていない。

## 5. 観測されたモデルの特徴と失敗

### Q

- seed501は左端11回・右端69回、seed502は左端9回・右端88回。中間3候補は両ゲームとも0回。
- 最後の判断では両seedとも右端を選び、その候補は1手予測でGO、他の候補には予測上の非GOがあった。実ゲームもGOとなった。ただし別候補なら実際に救えたという反実仮想までは未確認。
- 最後の選択Q予測は1259.59/1237.32点、実際のその判断からの追加得点は両方0点。差は最終得点の誤記ではなく、予測追加得点と実測追加得点の差。
- 同じ実ゲーム状態に対する3学習seedのargmaxが一致しない判断は79/80、96/97。これは学習seedによる判断の不安定さであり、3モデルそれぞれの自然GOゲームを実行したという意味ではない。
- 固定5座標は学習にも存在する。今回の問題を「0.37の座標教師がないから」と説明できない。一方、各盤面で未選択だった行動の教師がない問題は残る。

### V

- seed501の各座標(0,.25,.5,.75,1)の選択数は26/16/18/34/52、seed502は22/21/12/26/66。端への傾向はあるがQのような2端だけの選択ではない。
- 最後は両seedとも5候補すべてが予測GOだった。選択だけを見て「安全候補を無視した」とは扱わない。seed502では最後の判断に15点の実得点があり、終端未来0＋即時15点という処理と一致した。
- Vの学習seed間の選択不一致も、C自身の盤面で99/146、94/147あり、候補順位は安定しきっていない。
- Vはheuristicと同じ物理GO除外を使うので、Qとの差全体をVの精度だけの効果としない。V−heuristicの2seed比較は有望な兆候だが、長期的な高得点やスイカ生成の改善は未証明。

これらのモデルのMC教師は主にMCTS等の後続方針が得たreturnであり、モデル自身が毎手greedyに選んで続ける方針のreturnとは異なる。モデルの誤差、選択行動だけの学習、方針・盤面分布の変化が複合している可能性がある。モデル構造だけを原因と断定しない。

実得点の減少は記録されていない。ゲーム得点は単調増加で、全試行の保存・整合性監査を通過した。「将来追加得点の予測が下がること」と実ゲーム得点の低下を区別する。

各終端の果物数はQ 29/18、V 40/35、heuristic 40/38、MCTS 27。既存GO高さを超えた接触済み果物も各自然GOで確認し、詳細な位置・速度・種類・保持/NEXTは各 `result.json` の `final_state` と `actual_summary.json` の `GO_fruits` に保存した。

## 8. 次に優先するAIとデータ

強さの基準はMCTSを維持。学習型の優先候補は **1手物理探索＋V** とする。Q単独より行動が多様で、共通の物理安全処理を持つheuristicに対して両開発seedで高得点だった。まだMCTSを上回ってはいない。

次に実際に行う作業は、**Vの重み・5候補・GO処理を固定したまま、少数の新しい開発seedでheuristicとの自然GO対応比較を追加すること**。今回の2seedでモデルや重みを調整して予約Test19を開くことはしない。並行して再生ログを精密化し、候補順位教師の取得を安定させる。

Qを再学習するなら、単なるモデル大型化よりも、同じ盤面の未選択行動を含む結果とGOラベルが必要。成功するまでprefix失敗を無視したり、途中returnを自然GO教師にしたりしない。MCTSの強い盤面、Vの実軌跡、両者が異なる判断をする局面を区別して保存する。後続方針の違いも教師の属性として保持する。今回の新規データを既存学習データへ自動追加してはいない。

Qの提案を物理GO検査に通す方式も比較候補だが、今回は試しておらず改善したと扱わない。学習モデルのMCTS終端評価・事前分布への標準接続も行っていない。
